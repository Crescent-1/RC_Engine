# RC Engine B2B Growth Playbook

Strategy adopted 2026-07-07. The business: sell structurally-audited RC (reading
comprehension) item inventory to Indian test-prep institutions as premium retainers.
Engine economics: elite set ≈ ₹13 marginal API cost (hard cap ₹26), so pricing is
pure value capture — never discuss per-set cost with clients.

## Core positioning (never deviate)

- We do NOT sell "AI-generated RCs." We sell **un-crackable mock content**:
  argumentative structure as a sampled, audited variable, with a 9-channel novelty
  audit trail no human writer or vanilla-AI shop can produce.
- The enemy is not human writers. The enemy is **pattern leakage** — serious
  students pattern-matching a mock series' house style by RC 3, and faculty smelling
  same-author AI slop.
- Every sales artifact leads with *evidence*, not claims: the free Structural
  Repetition Audit of the prospect's OWN content is the wedge.
- Exclusivity is a **database constraint, not a promise**: cross-client combo-hash
  disjointness (blueprints table) means no two clients ever receive sets sharing an
  argumentative skeleton. This is the answer to "what if everyone uses this."

## Headline numbers (keep consistent across all client materials)

- **Tier 1 "Practice Bench"**: ₹15–20k/mo, 24 sets, shared component pool.
- **Tier 2 "Mock Vault"** (flagship): ₹40–55k/mo, 40 sets = one full 10-mock CAT
  VARC series/month, structural exclusivity, per-mock novelty certificate,
  trap-map teaching notes, 72h dispute SLA.
- **Tier 3 "Platform Feed"**: ₹75k–1.25L/mo, 100+ sets, CSV/API delivery,
  per-student novelty guarantees, difficulty metadata.
- Add-ons: category+city exclusivity +30–40%; one-time Legacy Corpus Audit ₹20–25k.
- Path to ₹1.5L MRR: 1 Platform + 2 Mock Vault, or 3 Mock Vault + 2 Practice Bench.
- Founding client (currently ₹10k/mo ≈ ₹200/set, 4–5× underpriced): upgrade to
  ₹18–20k grandfathered rate in exchange for testimonial + reference + case-study
  rights. Never churn them — they are the proof asset and house the faculty reviewer.

## Brand & pitch site

- Business name: **Blueprint Psychometrics** (serious, method-derived; adopted 2026-07-07).
  Use it consistently on emails, explainer PDF, MSA, invoices.
- Pitch website: deploy-ready standalone file at `website/index.html` (project root);
  also published as a Claude artifact for instant sharing. Sections: problem → method →
  9-channel audit table → gates → three tiers → blind audition → FAQ → contact.
- Pending brand hygiene: register a domain (e.g. blueprintpsychometrics.in) + domain
  email — the personal Gmail on the site is a placeholder and undermines premium pricing.

## Engine features that double as sales weapons

- `vet` / `backfill` fingerprinting → free Structural Repetition Audit of a
  prospect's existing mocks (the discovery wedge; costs ≈ ₹0).
- Student-simulation probe (§6 of ARCHITECTURE_REDESIGN.md) → the "crackability
  test" demo in auditions.
- Trap-map answer explanations (name the designed misreading) → faculty teaching
  notes; turns the client's faculty from threatened party into beneficiary.
- Fingerprint DB → content watermark/provenance: can prove which client leaked a set.
- Combo-hash uniqueness → auditable cross-client exclusivity.

## Operating constraints baked into this plan

- Solo operator, ≤1 hr/day ops budget; weekly batch cadence (generate Mon, review
  Tue/Thu, ship Fri). Exceptions are batched, never ad hoc.
- Single faculty reviewer is the true bottleneck, not the engine — see ops file for
  the tiered-review + piece-rate bench design before accepting client #3.
- CAT season: buying window for mock series is Jul–Sep; revenue trough Dec–Apr.
  Annual contracts with flexed delivery, not monthly rolling.
